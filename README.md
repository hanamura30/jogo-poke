# Descubra seu Tipo Ideal

Um teste interativo de personalidade que descobre quais tipos de Pokémon combinam com você, baseado nas suas respostas.

# Como funciona

1. Responda 5 perguntas sobre sua personalidade;
2. Descubra os 2 tipos de Pokémon ideais pra você;
3. Escolha um Pokémon de cada tipo (das 5 primeiras gerações);
4. Veja as informações completas dos seus parceiros!.

# Tecnologias usadas

- HTML5;
- CSS3;
- JavaScript (Vanilla).

# Estrutura do projeto

- `pokemon_natureza.html` — estrutura das telas;
- `estilo.css` — estilização e layout;
- `script.js` — lógica do jogo e banco de dados dos Pokémons.

# Paleta de cores

- Rosa suave e cinza;
- Fontes: Varela Round e Jersey 15.
